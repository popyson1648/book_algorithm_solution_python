# 第9章 スタックとキュー

固定容量配列・先頭添字・リングバッファを実装する。応用の式評価と括弧判定ではlistをスタックとして使う。

[問題番号から探す](../chap09.md) · [全体の使い方](../../README.md) · [差分と制約](../../docs/deviations.md)

| ファイル | 対応・目的 | 利用方法 | 計算量 |
| --- | --- | --- | --- |
| [block_01.py](block_01.py) | 章末問題9.2：スタックによる逆ポーランド記法の評価 | 直接実行可：`calc` | 時間・領域 O(N) |
| [block_02.py](block_02.py) | 章末問題9.3：括弧の対応をスタックで求める | 直接実行可：`check` | 走査 O(N)、対応のソートを含めると O(N log N)、領域 O(N) |

番号は問題番号ではなくコードブロック順。同じ問題の説明用断片や改善前後の実装も個別に収録している。

各ファイルの先頭に固定コミットの原文リンクを掲載。入出力のある例は原文の形式に従い、具体的な比較入力は [tests/cases.json](../../tests/cases.json) でファイルに対応するキーから参照できる。
