# 第3章 全探索

線形・ペア・部分集合の探索を手書きのループで追う。三重ループから二重ループへの改善も比較する。

[問題番号から探す](../chap03.md) · [全体の使い方](../../README.md) · [差分と制約](../../docs/deviations.md)

| ファイル | 対応・目的 | 利用方法 | 計算量 |
| --- | --- | --- | --- |
| [block_01.py](block_01.py) | 章末問題3.2：一致する要素の個数 | 直接実行可：`count_matches` | 時間 O(N)、入力領域 O(N) |
| [block_02.py](block_02.py) | 章末問題3.3：2番目に小さな値 | 直接実行可：`second_smallest` | 時間 O(N)、追加領域 O(1) |
| [block_03.py](block_03.py) | 章末問題3.4：最大差 | 直接実行可：`spread` | 時間 O(N)、追加領域 O(1) |
| [block_04.py](block_04.py) | 章末問題3.5：Shift Only | 直接実行可：`how_many_times`, `shift_only` | 時間 O(N log A)、追加領域 O(1) |
| [block_05.py](block_05.py) | 章末問題3.6・比較用コード片：3整数の和：三重ループ | 関数／クラス例：`count_triples` | 時間 O((K+1)³)、領域 O(1) |
| [block_06.py](block_06.py) | 章末問題3.6：3整数の和：一変数を消去 | 直接実行可：`count_triples` | 時間 O((min(K,N)+1)²)、領域 O(1) |
| [block_07.py](block_07.py) | 章末問題3.7：たくさんの数式 | 直接実行可：`expression_sum` | 時間 O(N·2^N)、追加領域 O(1)（算術演算回数） |

番号は問題番号ではなくコードブロック順。同じ問題の説明用断片や改善前後の実装も個別に収録している。

各ファイルの先頭に固定コミットの原文リンクを掲載。入出力のある例は原文の形式に従い、具体的な比較入力は [tests/cases.json](../../tests/cases.json) でファイルに対応するキーから参照できる。
