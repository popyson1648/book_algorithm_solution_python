# 原文との差分と入力前提

原文は `bf4af1b13b6fb1f58b8a921ab319096422f064d6` に固定。原文の正誤表にあるバケットソートのゼロの累積度数、BFSの始点、ヒープソートのコメントを確認した。以下の追加修正・補完はPython移植側の判断であり、著者による修正と混同しない。

## 共通の変更

- 整数の範囲はPythonの任意精度整数に従う。C++のオーバーフロー・範囲外参照・未定義動作は再現しない。
- 最小値・距離の初期化には、固定の「十分大きい整数」の代わりに `math.inf` を使う。実際の有限距離やDP値は整数のまま。従来の番兵を超える値も扱える。解がない場合の `inf` は、本来解の存在を前提とする問題の範囲外での補助的な返り値である。
- 全体入力をトークンとして読むCLIには入力サイズに比例するメモリが必要。表の計算量は主にアルゴリズム本体を表し、ストリーム読み込みと同じメモリ消費ではない。
- C++の参照引数は返り値またはオブジェクトの更新に置換。関数のグローバル作業配列は、引数やクロージャへ移し、繰り返し呼び出しても前回の計算が残らない形を基本とする。
- `chmin` / `chmax` の用途は値の代入と `min` / `max` で表現する。使われていないC++の補助テンプレートや `#include` は追加しない。補助関数自体を説明する掲載例は独立して残した。
- データ構造そのものの例を標準ライブラリで隠さず、学習上の独立性のため各例に実装を残す。

## 保持した意味・制約

- 第2章のループ、第10章の隣接リスト構築、第12章のソート、code 13.2には、原文と同じく標準出力がない。関数の返り値や更新後の配列を使って観察する。
- 再帰を用いる例は、Pythonの再帰上限に達しない入力サイズが前提。再帰上限を自動変更しない。特にFrogのメモ化再帰、鎖状の木・DFS、同値が多いクイックソートは深くなりやすい。反復版FrogやBFSは索引から比較できる。
- 部分和のDP・メモ化は非負整数と非負目標値を前提とする。無制限に使う値は正整数。ビット全探索・メモ化しない再帰全探索は負数でも数式通りに動くが、計算量は指数時間のまま。
- code 2.4は2点以上、最小値は非空、2番目の最小値は2要素以上、Frogは1足場以上、Slimesは1匹以上、木上の処理は1頂点以上の連結な木を前提とする。
- 2番目の最小値は重複を数える。`[1,1,3]` の答えは1。原文と同じ挙動。
- 「座標圧縮」の掲載例は重複を除去しない。`[10,10,20]` は `[0,0,2]` となる。連続した異なる値のIDへ変更しない。
- コイン問題は指定の6金種で支払える入力を前提とする。原文は支払不能を報告しない。区間スケジュールは非負時刻・開始<終了。射撃王は正の上昇速度。
- Aggressive cowsは2頭以上・小屋数以下。トポロジカルソートはDAG。ダイクストラは非負重み。
- ベルマン・フォードは始点から到達できる負閉路を検出し、フロイド・ワーシャルはグラフ全体の負閉路を検出する。
- クラスカルの本文例は非連結グラフなら最小全域森の重みを返す。章末15.2と15.3は連結グラフが前提。
- 章末15.2は原文の `(N+1)//2` 本目の辺を返す規則を維持。元問題の偶数NではN-1辺の中央値になる。奇数Nへ適用する際の一般的なメディアン定義は別途決める必要がある。
- 本文グラフの入力は0始まり。章末15章・18章の入力は1始まりなので、入力時に1を引く。章末13章は0始まり。
- 逆ポーランド記法の例は空白なし・1桁の数・正しい四則演算式。複数桁や空白区切りの汎用パーサには拡張していない。
- 括弧の例は `(` と `)` のみ。対応ペアのソートを含むため、コード全体はO(N log N)。原文解説のO(N)は走査部分に対応する。
- 計算量の改善前後を比較する例は遅い実装も残している。大規模入力の性能試験やオンラインジャッジへの提出は行っていない。
