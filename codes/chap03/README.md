# 第3章 全探索

線形・ペア・部分集合の探索を手書きのループで追う。三重ループから二重ループへの改善も比較する。

[全体の使い方](../../README.md) · [差分と制約](../../docs/deviations.md)

| ファイル | 対応・目的 | 利用方法 | 計算量 |
| --- | --- | --- | --- |
| [code_3_1.py](code_3_1.py) | 3.2：線形探索による存在判定 | 直接実行可：`contains` | 時間 O(N)、追加領域 O(1) |
| [code_3_2.py](code_3_2.py) | 3.2：最初に一致する添字の探索 | 直接実行可：`find_index` | 時間 O(N)、追加領域 O(1) |
| [code_3_3.py](code_3_3.py) | 3.3：線形探索による最小値 | 直接実行可：`minimum` | 時間 O(N)、追加領域 O(1) |
| [code_3_4.py](code_3_4.py) | 3.4：K以上となるペア和の最小値 | 直接実行可：`minimum_pair_sum` | 時間 O(N²)、追加領域 O(1) |
| [code_3_6.py](code_3_6.py) | 3.5：部分和問題のビット全探索 | 直接実行可：`subset_sum` | 時間 O(N·2^N)、追加領域 O(1) |

各ファイルの先頭に固定コミットの原文リンクを掲載。入出力のある例は原文の形式に従い、具体的な比較入力は [tests/cases.json](../../tests/cases.json) でファイルに対応するキーから参照できる。
